# Практическая работа №1 — HTML и базовая CSS-разметка

Учебный портал по дисциплине «Технологии разработки программного обеспечения».
Одна статическая страница на чистых HTML и CSS, построенная по данным из dataset.

## Технологии
- HTML5 — семантическая разметка
- CSS3 — Flexbox, медиазапросы, переменные

## Структура проекта
- `index.html` — единственная страница портала
- `css/styles.css` — все стили
- `images/logo.svg` — логотип в шапке
- `images/cover.svg` — обложка в hero-секции
- `data/content.csv` — данные карточек и таблицы
- `data/navigation.json` — пункты навигации

## Как используются данные dataset
- `navigation.json` → 4 ссылки в `<nav>` и 4 секции с id:
  `about`, `tracks`, `schedule`, `signup`.
- `content.csv` → 6 карточек в разделе «Направления» и 6 строк в таблице «Расписание».

## Как запустить
Просто открыть `index.html` в браузере.
